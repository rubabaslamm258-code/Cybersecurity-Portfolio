# TryHackMe: Defensive Security Intro Walkthrough

##  Objective
Understand the foundational pillars of cyber defense (Blue Teaming), including Security Operations Center (SOC) workflows, Digital Forensics and Incident Response (DFIR), Malware Analysis, and Threat Intelligence.

##  Concepts & Tools Covered
* **SOC Operations:** Continuous monitoring, log analysis, and alert triage using SIEM platforms.
* **DFIR (Digital Forensics & Incident Response):** Evidence collection, artifact investigation, and incident root-cause analysis.
* **Threat Intelligence:** Gathering adversary IOCs (Indicators of Compromise) to proactively harden defenses.
* **Malware Analysis:** Analyzing suspicious binaries through static and dynamic analysis techniques.

##  Key Exercises & Analysis
* **SIEM Alert Triage:** Analyzed simulated security alerts to distinguish between legitimate network activity and malicious unauthorized access attempts.
* **Incident Investigation:** Followed fundamental DFIR steps to trace malicious activity from initial access to detection.
* **Defensive Strategy:** Explored how security teams leverage Threat Intelligence feeds to update detection rules and block active threats.

##  Practical Takeaways for SOC Triage
* Effective cyber defense relies on correlation—combining SIEM event log alerts with Threat Intelligence and forensic evidence to form a complete incident picture.
