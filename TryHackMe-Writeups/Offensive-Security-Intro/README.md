# TryHackMe: Offensive Security Intro Walkthrough

##  Objective
Understand the fundamentals of offensive security, ethical hacking methodologies, and how offensive techniques inform proactive defense (Blue Teaming) and threat mitigation.

##  Concepts & Tools Covered
* **Core Concepts:** Offensive vs. Defensive Security, Penetration Testing, Red Teaming
* **Tools & Techniques:** Basic Web Application Reconnaissance, GoBuster / Directory Discovery, Exploitation Basics
* **Framework:** Ethical Hacking Methodology (Reconnaissance -> Exploitation -> Reporting)

##  Key Exercises & Analysis
* **Web Reconnaissance:** Explored target web directories to uncover hidden endpoints and sensitive administrative portals.
* **Exploitation Phase:** Demonstrated how unpatched web application vulnerabilities allow unauthorized file access or privilege escalation.
* **Defensive Application:** Identified how proper access controls, input sanitization, and robust logging prevent common offensive attack vectors.

##  Practical Takeaways for SOC Triage
* Understanding red team tactics allows SOC analysts to construct better SIEM detection rules and recognize malicious HTTP traffic patterns early in the kill chain.
